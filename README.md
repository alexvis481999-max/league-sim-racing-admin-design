# League Sim Racing — Admin & Design

Исходники админки и макет v16 для дальнейшей работы над интерфейсом.

[Карта API админки](ADMIN_API_MAP.md) — запросы по разделам, поля ответов, варианты данных, команды, статусы и привязка к новому макету. В техническом приложении — точные места вызовов и модели клиента.

## Состав

- `admin/` — исходники админки из `admin-source-20261009-215621.zip`.
- `shared/` — общие модули из `shared-frontend-backend-source-20261010-224621.zip` и минимальные зависимости админки, выделенные из исходных модулей.
- `design/LeagueSimRacing_Admin_All_Sections_v16.html` — HTML-макет.

Backend и публичный сайт в репозиторий не включены. Это снимок приложенных исходников, не версия Stage15.

## Установка и запуск

Нужны Node.js 22+ и npm.

```sh
cd admin
npm ci
npm run dev -- --port 5176
```

Для проверки сборки: `npm run build` в папке `admin`.

Для авторизации, загрузки данных и сохранения изменений нужен отдельно запущенный совместимый API. По умолчанию используется `http://localhost:3000`. Другой адрес можно задать через `VITE_API_BASE_URL` в `admin/.env.local`. Секреты и локальные настройки не публикуются.

Макет содержит демонстрационные данные и служит визуальным ориентиром.

## Подготовка отдельного проекта

Типы `PublicEvent`/`DisplaySchedule`, обработка URL изображений и правила обязательных плагинов перенесены в `shared`; импорты админки обновлены, чтобы сборка не требовала исходников сайта и backend. Остальная логика взята из приложенных архивов.
